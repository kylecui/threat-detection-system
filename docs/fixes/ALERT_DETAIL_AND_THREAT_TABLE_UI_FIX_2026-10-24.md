# 告警详情与威胁列表界面修复说明

版本：3.1.36  
日期：2026-10-24

## 修复内容

### 告警责任人

- 告警接口继续使用原有字符串字段 `assignedTo`，没有修改 API 或数据库结构。
- 列表改为从当前告警记录读取责任人，不再对 ProTable 已生成的显示节点执行字符串转换。
- 增加显示值保护：空值、空白值或意外的非字符串旧值统一显示 `-`，不会出现 `[object Object]`。

### 告警详情

- 左侧标签列在桌面端使用稳定宽度，标签保持单行；窄屏下缩小标签宽度和内边距。
- 右侧描述、提级原因和处置结论保留长文本换行能力，不改变原有抽屉宽度。
- 客户/设备、威胁详情、威胁情报查询结果和基础配置的 bordered Descriptions 同步使用标签单行和值区域长文本换行规则。

### 完成处置与提级处理

- 两个带 1000 字限制的文本域为 Ant Design 字符计数预留 22px 空间。
- 保留原有字符限制、提交锁、禁用状态和弹窗尺寸，仅修复计数与底部按钮重叠。

### 威胁列表

- 明细视图、分组视图和分组展开子表的业务列统一居中。
- 行选择复选框列、分组展开按钮列和带排序图标的表头同步居中。
- 各筛选控件补充可访问名称；路由、筛选条件、删除、批量删除、导出和详情打开逻辑保持不变。

## 同类问题处理

- ProTable 自定义列统一优先从 `record` 读取真实值，避免把渲染节点当作业务数据。
- 项目中仅告警中心的完成处置和提级处理使用 `showCount`，两处均已处理。
- 详情标签规则采用局部类名，未全局强制所有表格和非详情组件，避免破坏多列布局。
