# 设备管理界面修复记录（2026-10-21）

## 修复范围

- 修复“客户管理 → 设备管理”抽屉中，数据状态、绑定设备、编辑设备弹窗被抽屉遮挡的问题。
- 调整设备列表的信息层级和列宽，取消主列表横向滚动，保持原抽屉宽度不变。
- 统一客户、租户、用户和设备生命周期状态标签的语义颜色及明暗主题对比度。
- 本次按要求不处理客户端连接平台 `9080/tcp` 的网络、部署或安装逻辑。

## 根因与实施

设备抽屉使用全局 `zIndexPopup: 1200`，三个设备弹窗原先作为抽屉外的同级节点渲染，沿用 Modal 默认层级，导致弹窗内容处于抽屉遮罩和面板之后。现在三个弹窗统一使用 `DEVICE_MODAL_Z_INDEX = 1300`，并在关闭设备抽屉时同步取消详情请求、关闭子弹窗和重置表单，避免残留遮罩或孤立弹窗。

设备主表原有固定列宽合计约 1495px，并设置了 `scroll.x = 1495` 与全单元格强制不换行，因此即使抽屉宽度正常也一定出现横向滚动。修复后：

- 保留设备序列号、绑定、心跳、数据活跃、分析链路、最近数据和操作等核心信息。
- “描述”“分析链路”“最近数据”在较窄视口按响应式规则收起。
- 已发现主机数、创建时间和完整描述继续在“数据状态”弹窗中展示。
- 操作列改为带 Tooltip、可访问名称和统一 40px 点击区域的查看、编辑、解绑图标按钮。
- 主表改用固定表格布局，不再设置横向滚动宽度；设备管理抽屉尺寸未修改。

客户状态原先直接使用 Ant Design 预设色，在当前表格背景和主题组合下对比度偏低，且客户、租户、用户、设备各自维护颜色。现新增共享 `SemanticStatusTag`，统一成功、中性、警告、危险和信息五种状态色，并分别定义明暗主题样式。

## 同类问题排查

- 同一设备抽屉下的数据状态、绑定设备、编辑设备三个弹窗均纳入修复。
- 租户、用户与设备绑定状态均迁移到共享语义状态标签，避免同类低对比问题继续分散出现。
- 角色、订阅套餐、告警等级等标签表达的是类别或等级，不属于生命周期状态，本次保持原有业务色，避免改变既有语义。

## 验证项

- 前端 TypeScript 与 Vite 生产构建。
- 前端单元测试、ESLint 和 Prettier 检查。
- 发布契约：三个设备弹窗层级、抽屉关闭联动、主表无强制横向滚动、详情字段迁移、共享状态标签及明暗主题样式。
- 最新 Web 设计规范复核：响应式、键盘焦点、按钮可访问名称、触控目标和状态对比度。
