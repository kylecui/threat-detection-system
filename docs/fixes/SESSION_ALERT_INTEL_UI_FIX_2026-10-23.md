# 会话、告警与威胁情报使用说明（3.1.34）

## 登录会话

默认访问令牌有效期为 1 小时。令牌到期、被服务端判定无效，或账号/客户已停用时，页面会清理登录和数据范围并返回登录页；普通“无权限”403 不会把用户退出。刷新令牌的服务端有效期仍为 24 小时，但 Web 端不会在访问令牌到期后静默延长当前会话。

## 告警中心

- 默认只把 LOW、MEDIUM、HIGH、CRITICAL 评估创建为可处置告警，INFO 仍可在威胁列表中查询。
- 告警标题格式为“检测窗口 · MAC · 次数”；旧告警在元数据完整时也按此格式显示。
- 30 秒、5 分钟和 15 分钟是针对快速、持续、低速行为的并行聚合窗口，不是每隔对应时间主动扫描一次。
- 告警是否发送通知，由客户通知配置的严重级别、静默时段、频率限制和通道开关决定。

如需调整进入告警中心的最低等级，在安装环境中设置：

```dotenv
ALERT_INGESTION_MINIMUM_SEVERITY=LOW
```

可选值为 `INFO`、`LOW`、`MEDIUM`、`HIGH`、`CRITICAL`。

## 威胁情报

- “总指标数”是数据库中不同来源 IOC 记录的总量，不固定为 500。
- AbuseIPDB 的 500 表示一次拉取最多处理 500 条；重复拉取会更新既有记录，不会把总数重复累加。
- “活跃指标”排除已过期记录和已停用外部订阅源提供的记录。
- `internal` 是平台本地写入源，无需也不允许手工拉取。
- “记录目击”表示操作员确认该 IOC 在真实事件中再次出现；订阅源刷新不算目击。
- 停用外部订阅源不会删除历史 IOC，但这些记录暂不参与有效 IP 查询；重新启用后恢复。

## 总览中的 ICMP / ARP

`ICMP · 690` 表示当前范围和时间内记录了 690 条 ICMP 原始事件；`ARP · 645` 同理。二者没有 TCP/UDP 端口，因此从端口 Top 15 中分离展示，数量不等同于威胁评估数或告警数。
