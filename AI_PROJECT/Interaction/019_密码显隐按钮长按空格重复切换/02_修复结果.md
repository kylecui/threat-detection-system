## 1. 实际修复内容

本次仅处理登录密码显隐按钮对 Space/Enter 自动重复 keydown 的响应。在公共 `renderPasswordIcon` 中保留原有键盘路径，已按以下顺序增加防护：

```tsx
if (event.key === " " || event.key === "Enter") {
  event.preventDefault();
  event.stopPropagation();
  if (event.repeat) return;

  const button = event.currentTarget;
  button.click();
  button.focus({ preventScroll: true });
}
```

实际生产改动仅为第 138 行增加 `if (event.repeat) return;`。每个已识别事件都先取消默认行为和冒泡，再过滤自动重复；首次按下继续走 Ant Design 注入的 click 与可见状态，按住期间的重复事件不再触发切换。原有 `button.click()`、按钮焦点恢复及 `preventScroll` 保留，避免 rc-input 后缀 click 把焦点留回输入框。

不增加应用层 visible 状态、ref 锁、定时器、节流、全局键盘监听或 keyup 二次切换，不过滤或改写密码内容。公共函数继续用于普通登录密码、首次创建密码及确认密码。

新增独立浏览器测试 `frontend/e2e/login-key-repeat.spec.ts`，以真实 `keyboard.down` 重复和 `keyboard.up` 构造长按周期；保留原 `login.spec.ts` 中两次独立空格、鼠标切换、输入框回车和加载中重复点击回归。

同轮共享组件的颜色改动属于 `INTERACTION-018`，详见 [018 修复结果](../018_登录主按钮悬停文字对比度不足/02_修复结果.md)。本问题不调整样式、主题色或主提交按钮行为。

## 4. 事件序列与实际验证

### 4.1 修复前复现与修复后实测

修复前先执行普通登录 Space 专用红测，确实在第一次 `repeat=true` 时失败：首次 keydown 后 `type=text`，第一个重复 keydown 又变为 `type=password`，焦点仍在按钮且密码值未变。实际事件和快照见 `evidence/02-before-key-events.json`，失败报告与截图同时保留。该红测证明新用例能捕获原缺陷，并非只验证修复后的实现。

修复后 4 个真实浏览器场景全部通过：普通登录为英文 1440×900 桌面，首次创建为中文 390×600 手机短屏；两种模式分别验证 Space 和 Enter，首次创建同时覆盖密码和确认密码。每组填入合法用户名 `admin_019` 和符合 8–16 位规则的固定测试密码，确认字段与密码一致；没有用空表单的本地校验掩盖误提交。

以初始隐藏为例，最终实际序列为：

```text
初始 type=password
keydown Space/Enter repeat=false → type=text
keydown 同键 repeat=true        → type=text
keydown 同键 repeat=true        → type=text
keydown 同键 repeat=true        → type=text
keyup                           → type=text
下一次独立按下 repeat=false     → type=password
```

初始显示时已反向验证：首次按下变为隐藏，三个重复 keydown 和 keyup 均保持隐藏。松开后的两次独立按键仍分别切换；普通模式鼠标 click 和手机模式 tap 均正常，创建模式另一字段显隐不受影响。

事件附件共记录 **36 个真实 `repeat=true` keydown、84 个字段状态快照**。各阶段检查输入 type、动态名称、`aria-pressed`、密码值、44×44px 热区；键盘阶段焦点一直保留在对应显隐按钮，可见焦点轮廓存在。指针操作保留原有后缀点击后的聚焦行为，没有将其与键盘焦点保持混为一谈。

每个长按周期均在 `finally` 释放按键。隔离拦截的 `/api/v1/auth/bootstrap` 和 `/api/v1/auth/login` POST 在所有显隐周期中均为 **0**，初始化 GET 不计入。各场景实测数量如下：

| 场景 | `repeat=true` 数量 | 状态快照数 | bootstrap/login POST |
| --- | ---: | ---: | --- |
| 普通登录 Space | 6 | 14 | 0 / 0 |
| 普通登录 Enter | 6 | 14 | 0 / 0 |
| 首次创建 Space（密码及确认密码） | 12 | 28 | 0 / 0 |
| 首次创建 Enter（密码及确认密码） | 12 | 28 | 0 / 0 |
