## 覆盖的关键整改

- 客户归档后仍可见、可恢复，同一 ID 不再表现为“列表为空但创建 409”。
- 创建客户防重复提交，错误只提示一次；前后端 ID 长度与套餐枚举统一。
- Tenant Admin 与 Customer User 的路径、查询参数和列表均按认证主体收敛。
- 账户、租户或客户停用后，旧 JWT 不再继续获得业务访问权限。
- 停用客户不能新增设备绑定，V1 攻击日志和心跳不再写入该客户。
- 永久删除仅允许超级管理员，且必须先归档并通过跨服务依赖检查。
- 客户/租户弹窗不再使用固定弱密码自动创建管理员。
