# 3.1.34 会话、告警、情报语义与表格体验修复

日期：2026-10-23

## 问题与根因

- Web 端只把令牌放在本地存储，访问令牌过期后没有统一清理租户/客户作用域；部分请求又使用 `suppressGlobalError`，导致 401 被页面局部吞掉，范围选择器表现为“用户列表加载失败”而不是退出登录。
- API Gateway 在成功的 `Mono<Void>` 过滤链后使用 `switchIfEmpty`，可能把正常完成误判为用户不存在并尝试二次写 401。
- 告警标题直接暴露服务名与通用事件类型，信息密度低；INFO 级评估全部进入告警中心，单一设备的背景事件会淹没可处置记录。
- `internal` 是平台本地写入源，却与外部 REST 订阅源共用“拉取”操作；订阅刷新把处理条数累加为指标总数，并把刷新误算为目击，造成统计语义漂移。
- 总览、威胁列表、告警中心和设备表格各自定义 MAC、时间、数值与操作列宽，状态标签和 Tooltip 也缺少统一的视觉/交互约束。

## 实现

### 会话

- 新增统一会话终止器：清理 access/refresh token、用户、租户/客户作用域及相关 cookie，并通过单次事件通知应用树。
- JWT `exp` 到期、窗口重新获得焦点或接口返回认证 401 时直接跳转登录页，并显示“会话已过期”说明。
- 403 只有在后端明确返回稳定认证错误码时才终止会话；普通权限不足继续保留当前登录状态。
- API Gateway 的过期/无效令牌统一返回 401 和 `TOKEN_EXPIRED`/`TOKEN_INVALID`，修复成功过滤链被误判为空的响应生命周期问题。
- 默认 access token 为 1 小时，refresh token 为 24 小时；本版按产品要求在 access token 到期时退出登录，不静默延长页面会话。

### 告警

- 告警中心默认最低入库等级为 `LOW`，可用 `ALERT_INGESTION_MINIMUM_SEVERITY` 调整；INFO 结果仍保留在威胁评估链路，不创建处置告警。
- 新标题为“检测窗口 · 攻击者 MAC · 攻击次数”。历史行不改写数据库，前端在存在事件元数据时即时生成同样的本地化标题。
- 三个窗口分别表示 30 秒快速行为、5 分钟持续行为和 15 分钟低速行为，它们是同一事件流的并行聚合视角，不是扫描任务或固定轮询频率。
- 通知不再在消费端硬编码为 CRITICAL；保存后的告警全部交给客户通知配置中的严重级别、静默时段与频率限制判断。

### 威胁情报

- `internal` 标记为 `LOCAL_WRITE`，只接收平台内部或人工写入的 IOC，不再显示可执行拉取操作；不支持的外部源返回稳定的 422 `FEED_NOT_POLLABLE`。
- 外部源暴露可拉取能力和单次批量上限。AbuseIPDB 的 500 是单次 API 拉取上限，不是系统总指标上限。
- 指标数按当前有效唯一 IOC 重新计算，重复拉取不会累加；订阅刷新只更新时间，不增加“目击次数”。目击次数仅由显式“记录目击”操作增加。
- 关闭外部订阅源后，其来源指标不再进入有效指标数和 IP 有效查询；“活跃订阅源”只统计已启用且可轮询的外部源。
- 列表固定为内部源优先、其余按 ID，启停和拉取不改变顺序。

### Web 体验

- 平衡总览、威胁列表与告警中心的 MAC、等级、时间、数值和操作列；设备抽屉保留尺寸并取消不必要的强制横向滚动。
- 统一语义状态标签，确保文本垂直/水平居中并为明暗主题提供足够对比度。
- 表格图标操作统一为 40px 热区、可见 Hover/Focus、无障碍名称和稍向下贴近目标的延迟 Tooltip。
- 为检测窗口、无端口协议、指标总数、活跃指标、活跃外部源及单次拉取上限增加解释。
- `ICMP · N`、`ARP · N` 表示所选时间范围内没有 TCP/UDP 端口概念的原始协议事件数，不是端口号，也不等同于告警数。

## 兼容边界

- API 路由、请求/响应主体、权限模型、设备抽屉尺寸和部署入口保持不变。
- 既有历史告警、评估和 IOC 数据不删除；停用订阅源只影响“当前有效”查询，不物理删除其指标。
- 本轮不修改客户设备连接 `9080` 的链路，按用户要求排除在此次修复范围之外。
