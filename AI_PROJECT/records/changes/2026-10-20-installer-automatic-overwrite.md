# 旧版本自动覆盖安装

日期：2026-10-20  
版本：3.1.32

## 变更原因

根安装脚本原本已经能够同步覆盖 `/opt/threat-detection-system`，但没有显式识别已安装版本，也没有向操作员明确说明旧版本会自动进入覆盖升级。

## 实现

- 从发布包 `VERSION` 读取目标版本。
- 优先从安装目录 `.installed_version` 识别当前版本，兼容回退读取旧版本的 `VERSION`。
- 识别到旧版本后自动进入覆盖升级，不要求先卸载或交互确认。
- 缺少有效版本标记的历史安装按 legacy 覆盖处理。
- 同版本允许直接重新覆盖；显式执行较旧发布包时给出降级警告并保持原有覆盖行为。
- 覆盖过程继续保留 `.env`、Docker named volumes、升级前文件备份和失败回滚。

## 验收标准

- `3.1.31` 安装目录运行 `3.1.32` 发布包时显示旧版本识别信息并继续执行。
- 覆盖前不出现卸载要求或确认提示。
- 应用文件使用新发布包内容覆盖，旧发布包残留文件被清理。
- `.env`、数据库及其他 Docker named volumes 不被覆盖或删除。
- 覆盖失败时恢复原安装目录及旧服务。
