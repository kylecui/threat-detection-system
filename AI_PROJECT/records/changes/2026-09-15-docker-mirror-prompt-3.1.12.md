# 3.1.12 Docker 镜像源提示触发条件修正

## 问题

3.1.11 会在依赖检查阶段只要发现 Docker 已经存在，就立即显示国内镜像源切换命令。此时并未发生镜像拉取失败，提示过早，容易让操作员误以为安装已经出错。

## 修改

- 已有 Docker 环境在依赖检查、Compose 校验和正常镜像拉取过程中不显示换源提示。
- 单个基础镜像仍按既定次数重试。
- 只有镜像耗尽全部重试并最终失败，且 Docker 确实在安装器运行前已经存在时，才输出完整换源命令。
- Docker 由本次安装器新装时，仍按 3.1.10 策略自动安全配置三个国内镜像源。

## 不变范围

- 已有 Docker 的配置不会被自动修改，Docker 服务不会被自动重启。
- 镜像失败仍发生在事务变更前，不会停止旧业务或覆盖安装目录。
- 业务代码、数据库、Compose 服务关系、端口和数据接入不变。
