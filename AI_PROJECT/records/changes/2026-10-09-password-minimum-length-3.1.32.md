# 3.1.32 密码最小长度调整

## 变更原因

系统此前在首次管理员初始化、用户管理和客户管理员创建流程中要求密码至少 12 位并包含字母和数字。当前产品要求将密码规则统一调整为仅限制 8–16 位，不再限制字符组合。

## 统一规则

- 密码长度为 8–16 位。
- 不要求至少包含一个字母、数字或特殊字符。
- 客户管理员账号名继续使用 `<客户ID>-admin`，初始密码改为独立生成的 16 位安全随机字符串，不再使用 `<客户ID>@` 前缀。
- 已有密码哈希和登录流程不受影响，无需强制修改现有账号密码。

## 涉及范围

- Web 首次初始化管理员表单。
- 用户管理中的用户创建和密码修改。
- API Gateway 首次初始化及用户管理接口。
- Customer Management 客户管理员账号创建。
- 中英文界面提示、README、用户手册、当前需求规格和发布说明。

## 验收边界

- 满足字母和数字要求的 8 位密码可以通过前后端校验。
- 7 位和 17 位密码被拒绝。
- 8–16 位的纯字母、纯数字或混合字符密码均可通过校验。
